# CLAUDE.md — сайт urbanfactory.agency

Правила сайта Urban Factory. Источник — PROGRESS.md и задания в `C:\projects\Urban Factory\03_docs\site_review\`. Подробная история решений — в PROGRESS.md; при расхождении действует более позднее решение Михаила.

## Порядок работы
- Задания выполняются по разделам и по порядку; после каждого — `npm run build` (astro check + build) без ошибок.
- Изменения, которых нет в задании, — сначала спросить Михаила.
- В конце: commit, push в `main`, проверка деплоя (GitHub Actions → GitHub Pages, домен urbanfactory.agency), отчёт с разделом «Вопросы».
- Историю git не переписывать.
- Итоги и новые решения записывать в PROGRESS.md (дата, источник).

## Устройство
- Astro 7 + Tailwind 4. Языки HR (основной) / EN / RU; `/` → `/hr/`, hreflang x-default → HR.
- Строки интерфейса — `src/i18n/ui.ts`; тексты страниц — `src/i18n/copy.ts` (EN), `copy.hr.ts`, `copy.ru.ts`. Любой текст правится сразу на трёх языках.
- Кейсы — `src/content/projects/<lang>/<slug>.md`; Media — `src/content/media/<lang>/`; интервью — `src/content/interviews/<lang>/`.
- Обложки — `src/assets/projects/<slug>/cover.jpg` (≤2400px, JPG q≈82, прогрессивный); в frontmatter `cover` и `coverAlt` на трёх языках; `coverCredit` — только если нужна подпись правообладателя.
- PDF для сайта — `public/docs/` (reference-list и cv-veklenko, HR/EN; RU подхватывается автоматически, если есть файл `*-ru.pdf`, см. `src/lib/docs.ts`). PDF копируются готовыми из `03_docs/site_review/docs/`, сами PDF не редактируем.
- Меню из 5 пунктов: Agencija (= главная) · Projekti · Usluge · Mediji · Kontakt (`src/lib/nav.ts`).

## Тексты и факты
- Нигде не писать «мы / we / mi» — о себе в третьем лице: «Urban Factory», «Mihail Veklenko».
- Без политики и имён должностных лиц. Исключения (25.10.2026), только эти: Алексей Шапошников (MUF 2017), Михаил Солоницын (Зверево, 2018), Бесарион Месхи (ДГТУ, 2018).
- Не упоминать: старые сайты (urbanfactory.ru), фонд-донор Rostov 300, пилотный проект из задания 27.10.2026 (название не писать), ширину колеи 1435 мм и замену колеи в Таганроге и Новочеркасске, «Own initiative».
- Трамвай: не писать, что концессия расторгнута или приостановлена или что строительство остановлено; результат — «построено 6,3 км новых путей в Левенцовском районе».
- Стратегии 2018 (Ростов 2035, область 2030): участие в рабочей группе по транспортному разделу, часть материалов вошла в утверждённый документ; не «автор стратегии».
- TUN: место — только «kraj Erevana / near Yerevan / под Ереваном»; без финансов, имён партнёров и директора, фото людей.

- Политические акции и обращения — факт, цель, результат, без имён и обвинений.
